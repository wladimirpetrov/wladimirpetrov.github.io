Learning a dynamics correction for MPC

Learn a reusable model correction and investigate a validated handover from adaptive support to learned predictive control.

L1 / MPC Â· learning a dynamics correctionUpcoming research

The problem

Linearized prediction models leave part of the nonlinear underwater dynamics unexplained. Adaptive support can compensate while the vehicle operates, but does not by itself fulfill this projectâ€™s objective of retaining a learned residual model inside the predictor.

Research direction

The network learns a dynamics correction while L1 reference management and MPC remain active. The intended handover disables the adaptive reference contribution only after model and closed-loop validation, while retaining the learned correction inside the existing MPC structure. The objective is improved prediction and reduced dependence on continuous adaptive compensation within validated conditions.

About this preview

Research in development. The detailed video explains model mismatch, learning during operation, validation, the conditional handover and a subsequent command. No successful closed-loop handover is claimed. Any reduction in energy consumption or computation would require measurement; it is not assumed from switching off an adaptive layer.

Project focus

  • Learn residual dynamics during supported operation
  • Validate before disabling adaptive support
  • Retain learned correction inside MPC
