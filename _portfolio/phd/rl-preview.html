Offline RL tuning for AUV control

Use offline reinforcement learning to select controller settings for depth and heading maneuvers.

L1 / MPC Â· reinforcement-learning tuningUpcoming research

The problem

A working controller still requires suitable tuning: aggressive settings may overshoot, while conservative settings can settle slowly. The aim is to balance tracking, settling and control effort for the considered maneuvers.

Research direction

An offline reinforcement-learning agent selects the natural frequencies of the desired depth and heading reference dynamics in the L1 layer. A candidate pair is held fixed for a complete simulation episode, then the response informs the next choice. The selected tuning is validated and held fixed during deployment; adaptive compensation itself can continue to evolve.
